# 용어집 — 명세서 작성 모듈 UI 인벤토리 (2026-08-31)

> **기준**: 화면에 실제 렌더되는 표기만 수록한다(코드 대조 검증 완료). 괄호 안 `N`은 자동 번호.
> **용도**: 기능정의서(명세서 작성) 재작성의 용어 기준. 여기 없는 용어는 문서에 쓰지 않고, 새 용어가 필요하면 사용자 확인 후 추가한다.
> **표기 규칙(확정)**: 결과물 포함=**채택**(이미지 선별 단계만 **선택**) · 반복 동작=**다시 ~**+↻ · 위저드 문단=**항목**, 명세서 본문 문단=**단락** · 단계 마무리=**확정** · AI 제안 수락/거절=**적용/취소** · 진행 분모=8 · 판정 기준 없는 상태값(예: "작성완료") 금지.

## 1. 화면·모드 이름

| 용어 | 의미 | 표시되는 곳 |
|---|---|---|
| 새 명세서 작성 | 작업(명세서 1건)을 만드는 시작 폼 | 폼 제목 · 사이드바 메뉴 「새 명세서」 |
| 명세서 작성 | 명세서 모듈의 상단 헤더 이름(빵부스러기: `명세서 작성 / {작업 이름}`) | 헤더 |
| (위저드) | 8단계 작성 화면의 내부 명칭 — **화면에는 노출하지 않음**, 문서·툴팁에서만 "작성 단계"로 지칭 | 에디터 「← 작성 단계로」 툴팁 |
| 에디터 | 생성된 명세서를 편집하는 화면 | 사이드바 안내 문구 · 완료 화면 「에디터로 이동 →」 |
| 도면 편집기 | 도면 크롭·CAD 변환 도구(새 탭) | 도면 카드 버튼 · 새 탭 헤더 「도면 편집기」 |
| AI 어시스턴트 | 우측 보조 패널 이름. 부제로 역할 구분: 위저드=**작성 안내**, 에디터=**본문 수정** | 패널 헤더 · 모바일 FAB |

## 2. 8단계 이름 (스텝바 렌더 순서)

| 용어 | 의미 | 비고 |
|---|---|---|
| 업로드 | 직무발명서 PDF 업로드·분석 시작 | 1단계 |
| 발명 설명 | 추출 항목을 제안/종래로 검토·채택 | 2단계 |
| 이미지 선별 | 맥락에 쓸 이미지 선택·대표 지정 | 3단계 · 유일하게 "선택" 용어 사용 |
| 명칭·요약 | 발명의 명칭 후보 선택 + 요약 확정 | 4단계 · 필드명은 「요약」("개요" 금지) |
| 구성요소 | 구성요소 목록·부호 확정 (띄어쓰기 없음) | 5단계 |
| 명세서 도면 | 도면 채택(도 N)·대표도면·CAD 변환 | 6단계 |
| 청구항 | 권리범위 설정 → 독립항 세트 → 종속항 | 7단계 |
| 중간명세서 | 섹션·단락 검토 후 명세서 생성 | 8단계 |

## 3. 상태·진행 표기

| 용어 | 의미 | 표시되는 곳 · 표시 기준 |
|---|---|---|
| 분석 중 | 명세서 생성 전(1~8단계 진행 중) | 사이드바 작업 배지(brand) — 툴팁 `진행 단계: N/8 {단계명}` |
| 명세서 생성완료 | 명세서 생성을 거쳐 에디터 진입함(완료 판정 기준) | 사이드바 작업 배지(초록) |
| 확정 | 한 단계를 마무리해 다음 생성의 재료로 잠금 | 하단 바 주 동작 · 접힘 요약 ✓ · 패널 배너 「구성요소 확정」 |
| 확정됨 | 현재 단계가 확정 상태임 | AI 어시스턴트 헤더 배지(초록) |
| 다시 선택 | 확정 해제 후 그 단계로 복귀(이후 단계 재확정 필요 — 확인 다이얼로그) | 접힘 요약 우측 ✎ 버튼 |
| 펼치기 / 접기 | 확정 단계 요약 행을 열람(읽기 전용)/재접힘 | 접힘 요약 |
| 분석 중… / {단계} 분석 중… | 확정 직후 다음 단계 준비 로딩(0.9초) | 하단 바 비활성 버튼 · 본문 로딩 행 |
| 모든 분석 항목이 확정되었습니다 | 8단계 완료 화면 제목 | 완료 화면 |
| 명세서를 작성하고 있습니다 | 명세서 생성 오버레이(스피너+취소만, 시간·단계 미표시) | ⑧ 「명세서 생성 →」 후 전체 화면 |
| 보완 필요 | 채택 구성요소에 빈 필드(영문명·상위어·정의) 존재 — 진행 시 확인 | 구성요소 카드 배지(호박색) |
| ⚠ 번호 확인 | 종속항이 자기/후행 항을 인용(형식 오류) | 에디터 청구범위 배지(빨강) |

## 4. 채택·선택 계열 (핵심 구분)

| 용어 | 의미 | 표시되는 곳 |
|---|---|---|
| 채택 | 결과물(명세서)에 포함 — 체크박스. 미채택=흐림, 이후 단계에서 제외 | 발명 설명 항목 · 구성요소 · 종속항 (툴팁 `채택`/`채택 해제`) |
| 선택 | 이미지를 AI 맥락에 사용(이미지 선별 단계 전용) | 이미지 카드 체크(툴팁 `선택 (맥락에 사용)`) |
| 대표 | ③단계: 대표 이미지 1개(이후 생성 기준) / ⑥단계: 대표도면 1개(요약서 【대표도】) | 카드 라디오 `대표` · 확정 후 배지 |
| 도면 채택 / 참고만 | ⑥단계 세그먼트 — 채택=`도 N` 번호 부여·CAD 변환 대상, 참고만=AI 참고용 | 도면 카드 세그먼트 토글 |
| 선택됨 | 독립항 세트 중 현재 선택(1개만) | 세트 카드 우상단 라벨 |
| 선택 단락 / N개 선택 / 미선택 · 전체 문서 대상 | 에디터 AI 명령의 대상 표시 | 에디터 패널 정보 영역 제목 바 |

## 5. 번호·식별 표기

| 용어 | 의미 · 표시 기준 |
|---|---|
| 이미지 N | ③단계 추출 이미지 순번(채택 전). 툴팁으로 `원본 기호: {symbol}` 병기 |
| 도 N | 채택 도면 번호 — **채택 순서로 1부터 자동 재부여**. 원본 기호("도면N")는 화면에 노출하지 않음 |
| 부호 (100, 200…) | 구성요소 식별 번호 — 「부호 자동 부여」로 순서·계층 기준 부여(depth0=100·200, depth1=110·120, depth2=111…). API `symbol` |
| 청구항 N | 청구항 번호 — 목록 위치로 자동 부여, 순서 변경·삭제 시 본문 `제N항` 인용도 자동 갱신 |
| 종속항 N | 위저드 종속항 번호 — 전체 청구항 통산 |
| 세트 N | 독립항 세트 후보 순번(필터 후 표시 순) |
| N/8 | 진행 분모는 항상 8 (스텝바·확정 내용 `N/8 단계`) |

## 6. 분류·라벨 값 (API enum의 화면 표기)

| 배경 · 효과 · 기타 | background · effect · etc (도면 분류) | 이미지·도면 분류 select |

| 독립항 / 제N항 종속 | 인용 유무로 판정(`제N항` 패턴) | 에디터 청구범위 배지 |

| 용어 | 의미 | 쓰이는 곳 |

| 부호의 설명 | 부호 있는 구성요소를 `100: 명칭` 줄로 자동 조립한 섹션 | 에디터 「부호」 탭 |

| 구성요소 목록 | 구성요소 패널 리스트 헤더 | ⑤단계 |
| 확정 내용 | 확정된 단계 요약이 쌓이는 패널 정보 영역 | 위저드 AI 어시스턴트 |

| 수정 요청 / 취소 | 인라인 지시 전송/닫기 버튼 | 인라인 AI 카드 |
| 적용 / 취소 | AI 제안 카드의 수락/거절 — **모든 AI 수정은 확인 후 적용**(즉시 반영 없음) | 제안 카드(위저드·에디터 공통) |

| 수정안 생성 중... / 수정안을 만들고 있습니다... | AI 제안 대기 표시 | 전체 AI 수정 바 / 인라인 카드 |
| 변경이 필요 없다고 판단했습니다 | 전체 AI 수정 제안 0건 안내 | 전체 AI 수정 바 |
| 요청 분석 중... | 에디터 채팅 의도 분석 진행 트리 | 에디터 패널 |
| 답변 · 방향 확인 · 플랜 · 미지원 · 본문 수정 · 청구항 수정 · 도면 설명 수정 · 용어 교체 | 채팅 응답 의도 배지 8종 | 에디터(전부)·위저드(답변·방향 확인·미지원) |

| 대화 · 작성 안내 / 대화 · 본문 수정 | 패널 대화 영역 제목 바(위저드/에디터) | AI 어시스턴트 |

## 9. 다시 ~ (재실행 계열 — 전부 ↻ + 덮어쓰기 확인)

| 용어 | 대상 | 확인 문구 요지 |
|---|---|---|
| ↻ 후보 다시 생성 | ④ 명칭 후보 | (확인 없음 — 선택 전 목록) |
| ↻ 다시 정제 | ② 발명 설명 전체 | 채택·편집 항목이 정제본으로 대체 |
| ↻ 다시 분석 | ⑤ 구성요소 전체 | 명칭·정의·순서·부호가 추출 결과로 대체 |
| ↻ 다시 생성 | ⑦ 독립항별 종속항 / ⑧ 중간명세서 전체 / ⑧ 도면 설명 섹션 / 에디터 AI 제안 묶음 | 편집 내용이 새 초안으로 대체 (제안 묶음은 확인 없음) |
| 다시 변환 / ↻ 다시 변환 (영역부터) | 도면 편집기 CAD 재변환(지시문 입력 가능) / 완료 화면에서 처음부터 | — |
| 처음부터 다시 시작 (↺) | 위저드 전체 초기화 | 모든 분석 내용 삭제 |

## 10. 도면 편집기 (범위: 크롭 → CAD 변환)

| 용어 | 의미 · 표시 기준 |
|---|---|
| 영역 확인 | 1단계 — 파란 크롭 박스(8방향 핸들)로 변환 영역 지정. 추출/조정 BBox가 초기값 |
| 변환 영역 — 드래그하여 조정 | 크롭 박스 상단 라벨 |
| 영역 초기화 | 크롭 박스를 기본값으로 복원 |
| 변환 지시문 (선택) | CAD 변환에 전달할 추가 지시(API `user_instruction`) |
| CAD 변환 | 2단계 — 특허 흑백 선화 스타일 변환(API style-transfer). 진행 문구 `특허 도면 스타일(CAD)로 변환 중입니다…` |
| 버전 A / B / C | 변환 후보 3개(API `num_images=3`) — 클릭 선택, 확대 보기 |
| ✓ 이 버전으로 CAD 변환 완료 | 선택 후보 확정 → 완료 화면(초록 ✓)·메인 반영 |
| 변환 완료 / CAD 변환 완료 | 도면 목록 배지(초록) / 위저드·에디터 도면 카드 배지(초록) — stage `done` 기준 |
| 후보 선택 · 변환 중 · 영역 확인 | 도면 목록의 진행 배지(작업 단계별) |
| 도면 정보 · 명칭 · 분류 · 캡션 | 크롭 단계 우측 편집 필드(변경은 메인 도면 카드에 반영) |

## 11. 에디터 전용

| 용어 | 의미 · 표시 기준 |

| ← 작성 단계로 | 위저드 복귀(섹션 탭 행 좌측 고정, 편집 내용 유지) |

| 구성요소 이름 전체 변경 | 하이라이트 클릭 모달 — 본문·청구범위·부호의 설명·작성 단계 전체 치환, 부호는 유지 |
| + 단락 추가 / + 독립항 추가 / + 종속항 추가 | 전폭 점선 추가 버튼 |
| 클릭하여 편집 | 단락·청구항 카드 읽기 모드 툴팁 |
| 연관 구성요소 | 종속항과 연결된 구성요소 칩(부호+명칭, API `element_idxs`) — 위저드 ⑦ |
