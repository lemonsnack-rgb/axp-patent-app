## 4. 테스트 수행상 주의사항

1. **실제 입력 이벤트로 조작해야 한다.** 스크립트로 `element.click()` 을 호출하면 `pointerdown` 이 발생하지 않아 드롭다운이 열리지 않는다. `언어 설정` 에서 이 방식은 미동작으로 오판됐다.
2. **필터는 `검색` 을 눌러야 적용된다.** 필터 버튼만 토글해도 건수·URL이 바뀌지 않는다. 모든 필터 케이스 절차에 `검색` 클릭 단계가 필수다.
3. **요소 라벨이 상태에 따라 바뀐다.** `사이드바 접기/펴기` 는 접힘 시 `사이드바 펼치기` 로 변한다. 자동화 스크립트는 라벨 고정을 가정하면 안 된다.
4. **기본값 필터는 URL에 노출되지 않는다.** URL 파라미터만으로 상태를 검증할 수 없다.
5. **스크롤은 내부 컨테이너 기준으로 봐야 한다.** 특허 상세는 window 가 아니라 `div.flex.flex-1.flex-col.overflow-auto` 가 스크롤된다. `window.scrollY` 로 판정하면 항상 0이라 오탐이 난다.
6. **로드 완료를 기다려야 한다.** 상세 진입 직후(하이드레이션 전) 섹션 탭 클릭은 무시된다. 대기 후 재시도로 확인해야 한다.
7. **접근성 이름은 `aria-label` 속성이 아니다.** 패싯 checkbox 는 `aria-label` 속성이 없어도 라벨 텍스트에서 이름이 계산된다(`checkbox "등록 (725건)"`). 속성 부재만으로 접근성 이름 누락을 판정하면 오탐이다.
8. **대화상자·드롭다운 트리거는 실제 입력 이벤트가 필요하다.** 트리거는 스크립트 `click()` 에 반응하지 않는다. 반면 필터 토글 버튼·`검색` 제출·대화상자 내부 버튼은 스크립트 클릭으로도 동작한다.

## 6. 특허 검색식 작성·유효성 검증

### 공통 사전조건
- 화면 `특허 검색` (`/patent-front/patents`)
- 요소: `검색식` (textbox, multiline). **`<input>`/`<textarea>` 가 아니라 `div[contenteditable="true"][role="textbox"]`**
- 플레이스홀더는 별도 span: `예: 하이브리드 and 자동차 | *수소 자동차*`
- 빈 상태 안내: `특허 검색을 시작해 보세요` / `검색식을 입력하고 [검색]을 누르면 결과가 여기에 표시됩니다` / `불리언 연산자(AND/OR/NOT) 지원`
- 기본 필터: `국가`=`KR 한국`·`US 미국` / `문헌종류`=`전체` / `기간`=`최근 5년` / `상태`=`전체` / `검색어 범위`=`명칭+요약+독립항`

### 검증 안내 문구 (원문 2종)
- **V1** `검색식 형식이 올바르지 않습니다. 괄호·연산자(AND·OR·NOT)·따옴표 짝을 확인해주세요.`
- **V2** `검색어에 사용할 수 없는 문자가 있어요. 특수문자를 확인해주세요.`
