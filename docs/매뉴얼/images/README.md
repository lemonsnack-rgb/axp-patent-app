# CK.Patent 이용자 매뉴얼 — 캡쳐 원본

`CK Patent 이용자 매뉴얼.docx`에 들어간 화면 캡쳐 원본이다. 워드에는 이 파일들이 **재압축 없이 그대로** 삽입되고 표시 크기(가로 450pt)만 줄어들므로, 여기 있는 PNG가 최대 해상도다.

- 촬영 환경: `www.copykiller.com` 운영본 · `iwang@muhayu.com` 로그인
- 뷰포트 1440×900 · `deviceScaleFactor 2` → 전체 화면 캡쳐는 **2880×1800**
- 워드 배치 기준 약 **460 DPI** (2880px ÷ 6.25inch)
- 예시 검색어: 특허 `자동차 and 배터리`(117건) · 논문 `자율주행 and 센서`(13건)

| 파일 | 매뉴얼 위치 | 화면 |
|---|---|---|
| `1-1_카피킬러-사이드바.png` | 1.1 CK Patent 진입 | 카피킬러 사이드바의 `CK Patent` |
| `1-2_CK-Patent-검색메뉴.png` | 1.2 검색 메뉴 선택 | CK.Patent 특허 검색 초기 화면 |
| `2-1_특허-검색조건.png` | 2.1 검색 조건 설정 | 국가·문헌종류·기간·상태·검색어 범위 |
| `2-2_특허-검색식입력.png` | 2.2 검색식 입력과 검색 실행 | 검색식 입력 상태 (`and` 강조) |
| `2-3_특허-검색결과목록.png` | 2.3 검색 결과 확인 | 총 건수 + 결과 목록 |

| `3-3_논문-검색결과목록.png` | 3.3 검색 결과 확인 | 총 건수 + 결과 목록 |
| `3-4_논문-상세미리보기.png` | 3.4 상세 정보 미리보기 | 우측 미리보기 패널 |
| `3-5_논문-상세페이지.png` | 3.5 상세페이지 조회 | 논문 상세페이지 + `관련 논문` |

## 캡쳐 시 손댄 부분

실화면 그대로가 아닌 곳은 아래 두 가지뿐이다.

- `3-4` · `3-5` — `본문 보기 [내부 전용]` 버튼을 숨기고 촬영했다. 운영 화면에는 아직 노출되므로 프런트에서 제거해야 매뉴얼과 일치한다.
- 전체 — 브라우저 확장 프로그램이 주입한 요소(DeepL 입력 아이콘 등)를 숨기고 촬영했다.

## 다시 만들기

캡쳐를 교체한 뒤 아래를 실행하면 워드가 다시 생성된다. 문서를 Word로 열어둔 상태면 저장이 막히므로, 검증만 할 때는 출력 경로를 인자로 준다.

```
node scripts/build-manual.mjs
node scripts/build-manual.mjs /tmp/preview.docx
```
