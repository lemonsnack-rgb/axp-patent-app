■ 캡처별 기대 ↔ 실제

[오류 1] 분류코드-CurrentOnly-검색실패502
 기대 : [Current Only] 선택 시에도 정상 결과 반환 (Original or Current 의 부분집합)
 실제 : 카탈로그에 없는 IPCCM 으로 조립되어 서버 502 · 검색 자체가 실패
 근거 : 검색식 IPCCM:(G06F*) / POST patent-searches 502 /
        {"code":"HTTP_CLIENT_ERROR"} / 토스트 "검색에 실패했습니다."
        대조군 Original or Current → IPCM:(G06F*) → 134,975건 정상
        조립 API 응답의 warnings 가 빈 배열이라 클라이언트가 정상으로 보고 실행

[오류 2] 기간-기본값미적용-datePreset누락
 기대 : 화면에 [최근 5년] 이 선택돼 있으면 그 기간으로 좁혀진 결과가 나와야 함
 실제 : 표시만 [최근 5년] 이고 쿼리에는 일자가 실리지 않아 전체 기간 결과가 나옴
 근거 : URL ?lang=ko&query=자동차 (일자 파라미터 없음) / 158,490건 = [전체] 와 동일
        [최근 5년] 만 datePreset 누락 (10년 Y10 / 20년 Y20 은 정상)

[오류 3] 일자역전-검색무반응-전면차단
 기대 : 종료일 < 시작일이면 안내 문구 + [검색] 버튼 비활성
 실제 : 안내도 없고 버튼도 활성인데 검색이 실행되지 않으며, 검색식을 바꿔도 계속 막힘
 근거 : 역전 입력 후 patent-searches 요청 0건 / 검색식 변경 후에도 0건
        URL·건수는 직전 정방향 조건(자동차 2,628건) 그대로 / [초기화] 해야 복구
        논문 검색(발행연도)에서도 동일

[오류 4] 히스토리저장코드-미인식-재검색0건
 기대 : 히스토리에 저장되는 검색식이 파서가 인식하는 표현이고, [재검색] 시 정상 결과
        ※ [재검색] 은 저장된 검색식으로 다시 검색하는 기능. 건수 보존 기능이 아님
 실제 : 저장 코드 TAC_DSC 를 파서가 인식하지 못해 재검색 결과가 0건
 근거 : [전체 필드] 검색 401,480건 → 저장 TAC_DSC:(자동차) → 재검색 0건
        라벨 전체 필드 / URL DESCRIPTION / payload NAME_ABSTRACT_ALL_CLAIMS_DETAIL
        네 곳의 어휘가 모두 다름

[오류 5] 일자필드코드-하이픈표기-502
 기대 : 기능정의서 표기 AD:([2020-01-01 ~ 2020-12-31]) 로 일자 검색이 실행
 실제 : 문서 표기는 검증에서 막히고, 검증을 통과하는 하이픈 표기는 서버 502로 죽음
 근거 : 대괄호 표기 → disabled + V1 / 하이픈 표기 → 502 /
        AD:(20100101~20101231) → 172,072건 (유일하게 동작)
        V1 문구는 대괄호를 안내하지 않아 원인 파악 불가
        placeholder 에 일자 문법 없음 · AD 위젯 경로는 정상 동작 (대조군)

[오류 6] 검색식검증-문구와원인-불일치
 기대 : 표시 문구가 실제 차단 원인과 어긋나지 않을 것.
        원인 특정이 모호하면 공통 문구 하나로 안내
 실제 : 따옴표 짝 오류인데 특수문자 문구(V2)가 뜨고, V1 은 차단하지도 않는 연산자를 안내
 근거 : "하이브리드 자동차 → disabled + V2 / (하이브리드 and 자동차 → disabled + V1
        and 단독 0건 · 하이브리드 and 16,607건 · and and 1,684건 · @#$% 0건 → 전부 통과
        확정 방향 : 공통 문구 "검색식을 다시 확인해주세요." 로 통합

[오류 7] 국가전체-countries빈값-잔존
 기대 : 값이 없는 [전체] 는 URL 에서 키 생략, 값이 있는 [KR] 은 URL 에 반영
 실제 : 반대로 동작 — [전체] 는 빈 키 countries= 잔존, [KR] 은 URL 에서 사라짐
 근거 : [전체] …&countries=  (payload 에는 키 없음)
        [KR]   countries 없음 (payload 에는 ["KR"])

[오류 8] 상세검색-제거버튼-라벨동작불일치
 기대 : [✕ …제거] 는 [↵ 검색식에 추가] 로 넣은 필드절을 검색식에서 제거 (대칭)
 실제 : 검색식은 그대로 남고 패널의 입력란 행이 사라짐 — 라벨과 다른 대상이 제거됨
 근거 : [↵] 후 검색식 TI:(도서관) / [✕] 후에도 TI:(도서관) 유지, TI 행만 소멸
        버튼은 아이콘만 있고 화면 텍스트·title 툴팁 없음 (aria-label 로만 식별)

[개선 1] Enter키-검색미실행
 기대 : 검색식 입력 후 Enter → 검색 실행. Shift+Enter → 줄바꿈
 실제 : Enter 를 눌러도 검색이 실행되지 않고 입력창에 개행만 누적
 근거 : Enter 후 검색식 "자동차\n\n\n" / URL 변화 없음 / 결과 영역 빈 상태 유지
        검색은 [검색] 버튼 클릭으로만 가능. 논문 검색도 동일

[개선 2] 패싯-전체선택-부재
 기대 : 패싯 패널 최상단에 [전체 선택] 이 있어 "전체"를 명시적으로 고를 수 있어야 함
 실제 : [전체 선택] 이 없고, 체크박스를 전부 해제해야 전체 검색으로 돌아가는 암묵적 동작
 근거 : 패널 구성 = 값 6개 체크박스 + [취소]/[적용] 뿐
        [등록] 체크 → 적용 : fk_statuses=등록, 725건
        모든 값 해제 → 적용 : fk_statuses 제거, 1,684건 (전체 복귀)
        국가 · 권리상태 · 출원연도 · IPC 4개 패싯 모두 동일

[개선 3] 문헌번호-상세링크-미연결
 기대 : 상세페이지의 다른 문헌 번호를 클릭하면 해당 특허 상세로 이동
 실제 : 패밀리 · 선행기술문헌 · 인용/피인용의 문헌번호가 전부 단순 텍스트
 근거 : KR 10-2713513 B1 기준
        패밀리 문헌 5건 · 선행기술문헌 4건 전부 텍스트
        페이지 내 /patents/ 로 향하는 내부 링크 0개

[개선 4] 사이드바토글-aria-expanded부재
 기대 : 토글 버튼이 접힘/펼침 상태를 aria-expanded 로 노출
 실제 : 두 상태 모두 aria-expanded · aria-controls 없음
 근거 : 펼침 "사이드바 접기/펴기" · 접힘 "사이드바 펼치기" — aria-label 은 정상 전환
        폭 전환(240px ↔ 64px) 등 기능 동작 자체는 정상 → 접근성 보완

[개선 5] 히스토리-중복누적-실패검색저장
 기대 : 동일 검색식·동일 조건은 최신 1건만 유지, 실패한 검색은 미저장 (기획 확정)
 실제 : 검색 1회마다 조건 없이 저장돼 같은 검색식이 연속 누적, 502·검증 실패 건도 잔존

[확인 대기 1] 상태필터-출원공개심사중-3중복
