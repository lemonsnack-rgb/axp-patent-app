### 1.1 대상과 설계 원본의 관계

- **설계 원본** — 저장소 `react-app`(AXP 목업)의 `기능정의서.md`·`specCatalog.ts`. **`기대 결과`의 유일한 출처.**
- **구현체** — copykiller.com/patent-front (CK.Patent 실서비스). `실제 결과`의 출처.
- **결함** — 위 둘의 불일치. **설계 원본에 근거가 없으면 판정하지 않는다** (`근거 없음`으로 기록만 남긴다).
- 이 문서의 기대 결과·참고 관측값은 전부 위 설계 원본 또는 2026-08-10 실측 기록에서 가져왔다. 추측으로 만든 항목은 없다.

### 1.2 문서 사용법

1. §3 실행 전 준비를 완료하고 환경 정보(계정·app-version·일자)를 기록 파일 표지에 적는다.
2. 각 케이스의 **사전조건 → 절차** 순서로 조작하고, **기대 결과**와 대조해 `실제 결과`·`판정`·`확인일`을 기입한다 (md 직접 기입 또는 xlsx). 절 진행 순서·중단 시 재개는 §3.1, 확인 단계(aria 속성·URL·스크롤 등)의 구체 조작은 §3.2를 따른다.
3. 건수는 데이터 갱신에 따라 변한다. **`참고 관측값(2026-08-10)`은 스냅샷이며 불일치 자체는 결함이 아니다.** 판정은 §6의 **불변식(검산 규칙)** 기준으로 한다.
4. `Fail` 판정 시 결함목록 절차에 따라 신규 등재하되, 먼저 §15(기지 결함)·§16(결함 아님 확정)과 대조해 중복 등재·재조사를 피한다.
5. 기지 결함(BUG-001~034 + D40~D44, 등재 39건)의 회귀 확인은 §15에서 별도로 수행한다 (본문 케이스는 정상 기대 기준으로 작성됨).

### 3.1 수행 순서·운영

**권장 수행 순서** — 뒤 절이 앞 절의 화면 상태(검색 실행 상태 등)를 재사용하므로 절 순서대로 진행한다.

| 순서 | 절 | 비고 |
|---|---|---|
| 0 | §3 실행 전 준비 (P1~P5) | 환경 정보를 xlsx `표지`에 기록 |

| 2 | §9 특허 검색식 | 001~007(검증) → 008~018(건수·검산) → 019~029(신규). 건수 케이스 전에 `기간`=`전체` 명시 설정 |

| 4 | §11 특허 결과 목록 | `하이브리드 and 자동차` 실행 상태에서 시작. 010(패싯)만 `도서관` 기준 |
| 5 | §12 특허 상세 | 진입은 TC-PAT-LST-011(`새 탭에서 열기`) 경유 — `탭 닫기` 검증(T10) 겸함 |
| 6 | §13 논문 입력 → §14 논문 목록·상세 | 특허와 대조 항목(유효성·선택 삼상 등)은 특허 결과를 먼저 기록해 둘 것 |

**결함 발견 시** — §16(결함 아님 32건)·§15(기지 39건)와 대조 → 신규면 `테스트-결함목록.md` 양식(심각도·재현 절차·기대·실제·영향)으로 등재하고 케이스 `비고`에 ID를 남긴다.

### 3.2 검증 도구 조작법 (Chrome DevTools — F12)

절차의 확인 단계별 구체 조작. 콘솔 명령은 대상 요소를 Elements 패널에서 클릭해 `$0`으로 잡은 뒤 실행한다.
**주의(T1·T8)**: 아래는 전부 **읽기(확인) 용도**다. 드롭다운·대화상자 트리거를 콘솔 `$0.click()`으로 여는 것은 오탐을 만든다 — 조작은 실제 클릭으로 한다. (토글 버튼·`검색` 제출·대화상자 내부 버튼은 스크립트 클릭도 동작하나, 수동 수행 시에는 전부 실제 클릭 권장)

| 확인 대상 | 방법 |
|---|---|
| URL 파라미터 | 주소창에서 직접 확인. 인코딩 풀어 보기: 콘솔 `[...new URL(location.href).searchParams]` |
| `aria-pressed`/`aria-expanded`/`aria-selected`/`disabled` | 요소 우클릭 → 검사 → Elements에서 속성 확인, 또는 `$0.getAttribute('aria-pressed')` |
| 접근성 이름·역할 (N7, T7) | Elements → 우측 `Accessibility` 패널 → `Computed Properties`의 `Name`/`Role`. **`aria-label` 속성 유무로 판정하지 말 것**(T7 — 이름은 라벨 텍스트에서 계산됨) |
| a11y 트리 전체 채집 | `Accessibility` 패널 상단 `전체 페이지 접근성 트리 사용` 활성화 → Elements 트리가 접근성 트리로 전환 |
| `<html lang>` | 콘솔 `document.documentElement.lang` |
| 상세 화면 스크롤 위치 (T5) | 콘솔 `document.querySelector('div.flex.flex-1.flex-col.overflow-auto').scrollTop` — `window.scrollY`는 항상 0이므로 쓰지 않는다 |
| 대화상자 개수·중첩 (T9) | 콘솔 `document.querySelectorAll('[role="dialog"]').length` — `querySelector`(단수)는 첫 번째만 반환 |
| 링크 href·`rel` | 링크 우클릭 → 검사 → `<a>`의 `href`/`rel` 확인, 또는 `$0.href` / `$0.rel` (`새 탭에서 열기`=`rel="opener"` — T10) |
| 텍스트 분량 (청구범위 토글 등) | 영역을 `$0`으로 잡고 `$0.textContent.length` |
| 초록 표시 문자수·말줄임 문자 (TC-PAP-DET-002) | `$0.textContent.length` + 말줄임 문자 판별 `$0.textContent.at(-1) === '…'` (`true`=U+2026 `…`, `false`이고 끝이 `...`이면 ASCII 3자) |
| 검색어 하이라이팅 | 콘솔 `document.querySelectorAll('mark').length` (논문 목록 실측 방식), 특허 명칭은 검사로 검색어가 별도 요소로 분리 렌더되는지 확인 |
| 결과 행 수 (페이지 크기 검증) | `페이지당 개수` 표시값과 화면의 행/카드 수를 끝까지 스크롤하며 육안 계수로 대조. DOM 계수가 필요하면 요소 검사로 실제 컨테이너 구조를 확인한 뒤 사용한다 (실측 검증된 셀렉터 없음) |
| 사이드바 폭 (TC-CMN-007) | `$0`으로 `role="complementary"` 요소를 잡고 `$0.getBoundingClientRect().width` |
| 검색 히스토리 버튼 수 검산 (BUG-008/009) | 패널을 `$0`으로 잡고 `$0.querySelectorAll('button').length` — 항목수×2+트리거 1과 비교 |
| `app-version` (P2) | **확인 방법 미확정** — 기준값 `2.16.1`(2026-08-10)만 실측 기록에 있음. 최초 수행 시 확인 위치를 실측해 본 절을 갱신한다 |
| 탭 실제 종료 (T10) | 브라우저 탭 스트립에서 육안 확인 (탭이 사라져야 `닫힘`) |

## 5. 수행 주의사항 (오탐 방지 — 2026-08-10 순회에서 실제 오탐을 유발했거나 유발 가능했던 10건)

| # | 주의사항 | 관련 케이스 |
|---|---|---|
| T1 | **실제 입력 이벤트로 조작한다.** 스크립트 `element.click()`은 `pointerdown`이 발생하지 않아 드롭다운이 열리지 않는다 (`언어 설정`에서 미동작 오판 발생) | TC-CMN-003, 모든 드롭다운·팝업 |
| T2 | **필터는 `검색`을 눌러야 적용된다.** 토글만으로는 건수·URL이 바뀌지 않는다. 모든 필터 케이스 절차에 `검색` 클릭이 포함돼 있다 | TC-PAT-INP-003 외 필터 전체 |
| T3 | **요소 라벨이 상태에 따라 바뀐다.** `사이드바 접기/펴기`↔`사이드바 펼치기`, `항목별 상세검색 …필드별 조합`↔`항목별 상세검색`. 라벨 고정을 가정하지 않는다 | TC-CMN-007/008, TC-PAT-INP-012 |
| T4 | **기본값 필터는 URL에 노출되지 않는다.** URL 파라미터만으로 상태를 검증할 수 없다 | TC-PAT-INP-009 |
| T5 | **스크롤은 내부 컨테이너 기준으로 본다.** 특허 상세는 window가 아니라 `div.flex.flex-1.flex-col.overflow-auto`가 스크롤된다. `window.scrollY`로 판정하면 항상 0 → 오탐 | TC-PAT-DET-004 |
| T6 | **로드 완료를 기다린다.** 상세 진입 직후(하이드레이션 전) 섹션 탭 클릭은 무시된다. 대기(약 6초) 후 재시도로 확인한다 | TC-PAT-DET-004, BUG-032 |
| T7 | **접근성 이름은 `aria-label` 속성이 아니다.** 패싯 checkbox는 속성이 없어도 라벨 텍스트에서 이름이 계산된다 (`checkbox "등록 (725건)"`). 속성 부재만으로 누락 판정하면 오탐 | TC-PAT-LST-005, TC-PAP-LST-007 |
| T8 | **대화상자·드롭다운 트리거는 실제 입력 이벤트가 필요하다.** 반면 필터 토글·`검색` 제출·대화상자 내부 버튼은 스크립트 클릭으로도 동작한다 | 자동화 병용 시 전체 |
| T9 | **대화상자는 중첩될 수 있다.** 논문 미리보기 오버레이 위에 본문 뷰어가 겹쳐 열린다. `querySelector('[role="dialog"]')`는 첫 번째만 반환 → `querySelectorAll`로 전부 확인 | TC-PAP-LST-004, TC-PAP-DET-003 |
| T10 | **`탭 닫기`는 진입 경로에 따라 동작이 다르다.** `새 탭에서 열기`(`rel="opener"`)로 열린 탭에서는 탭이 닫히고, 주소창 직접 진입 시에는 목록으로 이동(fallback). 반드시 의도된 경로에서 검증한다 | TC-PAT-DET-011, TC-PAP-DET-007 |

## 6. 건수 판정 기준 — 불변식과 기준 스냅샷

### 6.1 불변식 (데이터가 갱신돼도 성립해야 하는 검산 규칙)

| # | 불변식 | 근거 |
