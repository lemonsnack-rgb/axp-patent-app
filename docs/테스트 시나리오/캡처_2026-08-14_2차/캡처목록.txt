 실제 : 검색 필드 82종 중 27종이 HTTP 502 — 고를 수 있는 필드의 약 1/3 이 검색 불가
 근거 : 검색 필드 82종 전수 : 정상 200 = 53종 / 502 = 27종 / PRC 504 · NPRD 400
          502 27종 : WAP INVC AC PCN UCM UC FI FTC CAC ASY LY JIC BCC BCN
                     FCC FCN NPCY SEYN SESO SEN SEDC SEDD SEQY CAD LRD NRDS NRDE
          UCM · UC · FI · FTC 는 화면 카탈로그 노출 필드인데 선택하면 502

        대조군 — 같은 분류코드 그룹인데 결과가 갈림
          IPCM:(G06F*) 200 · 134,975건    IPC:(G06F*)  200 · 204,738건
          CPCM:(G06F*) 200 · 102,535건    CPC:(G06F*)  200 · 163,110건
          UCM:(707) 502 / UC:(707) 502 / FI:(G06F*) 502 / FTC:(5B075*) 502

        실패 지점 절단
          미등록 코드 ICM · IPCR · ZZZZ → 400 "지원하지 않는 검색 필드 코드입니다."
          위 27종                       → 400 아닌 502
          → 서버는 유효 코드로 인식. 프론트 조립 오류 아님

        ※ 이전 기재 "카탈로그 미등재 코드로 조립되어 502" 는 위 400/502 실측으로 정정
