 V1  "검색식 형식이 올바르지 않습니다. 괄호·연산자(AND·OR·NOT)·따옴표 짝을 확인해주세요."
 V2  "검색어에 사용할 수 없는 문자가 있어요. 특수문자를 확인해주세요."

 ※ V1·V2·V3 는 본 문서의 편의상 약칭이며 제품 내부 코드가 아닙니다.

1. 기획 확정 사항  (2026-08-14)
═══════════════════════════════════════════════════════════

 1) 기간 필터
    - 기본값을 '전체'로 변경 / 프리셋 구성(5·10·20년)은 현행 유지
    - [최근 5년] datePreset 누락은 함께 수정

 2) 검색식 유효성 검증
    - 차단 범위는 현행 유지 (괄호 짝 · 따옴표 짝 · 필드코드)
    - 원인 특정이 모호한 경우 공통 안내 문구 사용 (예 "검색식을 다시 확인해주세요.")

 3) 검색어 범위
    - '상세설명 → 전체 필드' 라벨 변경은 의도된 사항
    - 잔재 어휘 3종(저장 코드 · URL · payload) 전부 통일

 4) 일자·연도 역전 입력
    - 안내 문구 표시 + [검색] 버튼 비활성

 5) 항목별 상세검색 [✕] 버튼
    - 동작을 라벨에 맞춤 (검색식에서 해당 필드절 삭제)

 6) 검색 히스토리
    - 중복 제거 적용 / 실패한 검색은 미저장

 7) 일자 필드코드 표기
    - 현행 표기 YYYYMMDD~YYYYMMDD 를 정식 표기로 확정
    - 기능정의서 대괄호 표기는 문서 정정 대상

 8) 분류코드 [Current Only]
    - 정상 동작해야 함. 옵션 비활성화·제거는 대안으로 인정하지 않음

 9) 신규 필수 개선 3건 추가
    - Enter 키로 검색 실행
    - 패싯에 [전체 선택] 제공
    - 상세페이지 내 문헌번호를 해당 특허 상세페이지 링크로 연결 (상세페이지 내 전부)

10) 상태 필터 3중복 — 확인 대기. 현재는 수정하지 않음 (§5)

11) 아래는 결함에서 해제 (§6)
    - 논문 목록 부분 선택 mixed 표현 — 과한 표현으로 판단
    - 논문 초록 말줄임 문자 규격 — 다루지 않음
    - 다국어 전환 시 한국어 잔존 — 다루지 않음
    - PDF 원본 열기 내부 URL · 논문 초기화 범위 · 관련 논문 자기 자신 포함 — 현행 유지

12) 선행기술문헌 표기 혼재 — 데이터 문제로 본 문서 범위 밖 (§7)

[오류 1]  P0
CK Patent_[오류] 분류코드 Current Only 선택 시 검색 실패(502)
          대상 : 특허 검색 – 항목별 상세검색 – 분류코드
          기존 : F-02
          캡처 : 오류01_분류코드-CurrentOnly-검색실패502.png
───────────────────────────────────────────────────────────

▸ 수정 사항 요약
   - 분류코드 검색 대상을 [Current Only]로 선택 시 서버 502
   - 미존재 필드코드(IPCCM / CPCCM)로 조립되는 것이 원인

▸ 기대 결과
   - [Current Only] 는 정상 동작해야 함 (옵션 비활성화·제거는 대안으로 인정하지 않음)
   - Original or Current 대비 건수가 같거나 적음 (부분집합)

▸ 재현 방식
   1. 특허 검색 진입 → [초기화] → [항목별 상세검색] 펼침
   2. 분류코드 IPCM 입력란에 G06F* 입력
   3. [분류코드 검색 대상] = Original or Current (기본값) 로 [검색] → 정상 (대조군)
   4. [초기화] 후 2번 반복, [분류코드 검색 대상] 을 Current Only 로 변경 → [검색]
   5. CPCM 입력란에 C01C* 입력하고 3~4 반복
   ※ 관찰 지점 : 조립된 코드 · Network 탭 응답 코드 · 화면 토스트

▸ 현재 상태
   - IPCM / Original or Current   조립 IPCM:(G06F*)    정상 134,975건
   - IPCM / Current Only          조립 IPCCM:(G06F*)   HTTP 502
   - CPCM / Current Only          조립 CPCCM:(C01C*)   HTTP 502
   - 응답 : {"code":"HTTP_CLIENT_ERROR","message":"외부 시스템 연동 중 오류가 발생했습니다."}
   - 토스트 : "검색에 실패했습니다."
   - IPCCM / CPCCM 은 [+ 검색 필드 추가·확장] 카탈로그 미등재 코드
   - 조립 API 응답 {"query":"IPCCM:(G06F*)","warnings":[]}
     → warnings 가 비어 있어 클라이언트가 정상으로 보고 실행

▸ 상세 수정내역
   1) composition API 수정 — 최우선
      - scope=CURRENT 에 대해 생성하는 IPCCM / CPCCM 을 서버 지원 코드로 교체
      - 서버측 지원 코드가 없다면 백엔드에 해당 코드 지원을 추가
   2) composition 응답 warnings 활용 — 미지원 코드는 실행 전 차단
   3) 5xx 안내 문구 : "검색에 실패했습니다. 잠시 후 다시 시도해 주세요." + [다시 시도]
   4) 실패 검색 히스토리 미저장 — [개선 5]에서 함께 처리

▸ 검증 방법
   - IPCM · CPCM + Current Only 모두 502 없이 결과 반환
   - Current Only 건수 ≤ Original or Current 건수 (134,975 이하)

    - 참고 : /patent-searches/KR%2010-2620258%20B1 → 200 / 13자리 숫자 → 404

 2) 국가 필터 KR 외 선택 차단  (기존 F-01)
    - KR 외 클릭 시 얼럿 "데이터 준비중입니다 / 선택한 국가의 특허 데이터를 준비하고 있습니다."
    - 적재 범위(한국)와 일치 → 정상 동작

 3) 기간 [최근 5년] 결과 0건  (기존 F-03 중 1개 문항)
    - 검색 인덱스 최신 출원일 2019-07-05. 적재 범위 이슈이며 프론트 수정 대상 아님

 4) PDF 원본 열기 내부 URL 노출  (기존 F-23)
    - 현행 유지로 확정. 내부 전용 기능이므로 의도된 노출로 판단

 5) 논문 [초기화] 후 pageSize · sort 잔존  (기존 P-02)
    - 현행 유지로 확정. 검색 조건이 아닌 표시 옵션

 6) 논문 상세 관련 논문에 자기 자신 포함  (기존 F-15)
    - 현행 유지로 확정. 섹션 내용이 "검색결과 상위 10건" 그대로이므로 자연스러움
    - 참고 : URL 에 query 파라미터가 있을 때만 노출되는 구조

 7) 논문 목록 부분 선택 mixed 미표현  (기존 F-13)
    - 전체 선택의 mixed(삼상) 표현은 과하다고 판단 → 결함 해제
    - 실측 : 카드 aria-checked=true, [전체 선택] aria-checked=false

 8) 논문 초록 말줄임 문자 규격  (기존 F-14)
    - 다루지 않음
    - 참고 : 지적 내용은 말줄임 자리의 문자 종류(ASCII "..." vs U+2026 "…")였으며
      잘리는 길이가 본문마다 다른 것은 정상 동작으로 판단

 9) 다국어 전환 시 한국어 잔존  (기존 F-18)
    - 다루지 않음
    - 참고 실측 : html lang="ko" 유지 / 결과표 Status 컬럼 공개·등록 /
      페이지네이션 aria "이전·다음 페이지 그룹" / 푸터 "카피킬러 DIFF"

10) 특허 상세 섹션 탭 스크롤 · 미존재 필드코드 안내  (기존 F-08 · F-19)
    - 2026-08-12 지적분이 조치 완료됨 → §10 참조

   - 응답 hits[].fields : application_number / open_number / register_number /
